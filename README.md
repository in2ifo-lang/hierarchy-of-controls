# Hierarchy of Controls · Build a safer workplace

An interactive safety-training game by **B/A The Rule**. Learners try real controls on four workplace hazards (a forklift aisle, a noisy saw, a pillar drill and a solvent tank) and see which ones actually make work safer.

- **Play:** open `index.html` (or the GitHub Pages link for this repository). Works on phones and computers. English and Arabic.

## التسلسل الهرمي للتحكم في المخاطر
لعبة تدريبية تفاعلية في السلامة من **B/A The Rule**. يجرّب المتدرّب ضوابط حقيقية على أربعة مخاطر في بيئة العمل ويرى أيّها يجعل العمل أكثر أمانًا. تعمل على الهاتف والكمبيوتر، بالعربية والإنجليزية.

---
Educational use. The scenarios are simplified examples; real controls must be selected, installed and verified for the actual workplace.
